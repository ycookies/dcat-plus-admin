# 路由权限中文说明开发指南

> 本文说明如何让“资源路由”和“单路由”在角色权限页显示可读的中文名称与功能说明。

## 一、最终展示效果

资源路由：

```text
用户管理                 /member-user
管理平台注册用户和账号状态

预览
查看用户列表 + 查看用户详情

新建
新建用户 + 保存用户
```

单路由：

```text
接口文档   [开发工具]
查看后台 OpenAPI 文档
GET /openapi-docs
```

## 二、扫描优先级

中文说明按以下顺序解析：

1. 单路由 `->permissionLabel()` 元数据；
2. 资源语言包 `permissions.routes.<route-name>`；
3. 资源语言包 `permissions.actions.<controller-method>`；
4. 资源语言包 `labels` 与框架默认动作翻译；
5. 没有任何说明时，回退到路由名、HTTP 方法和 URI。

越靠前的配置优先级越高。

## 三、资源路由

### 1. 路由定义

```php
$router->resource('member-user', MemberUserController::class);
```

### 2. 语言文件

`MemberUserController` 对应：

```text
lang/zh_CN/member-user.php
```

### 3. 最小配置

```php
return [
    'labels' => [
        'MemberUser'  => '用户管理',
        'member-user' => '用户管理',
    ],
];
```

仅配置 `labels` 后，资源卡片就会从 `MemberUser` 变为“用户管理”。

### 4. 推荐配置

```php
return [
    'labels' => [
        'MemberUser'  => '用户管理',
        'member-user' => '用户管理',
    ],

    'fields' => [
        // ...
    ],

    'options' => [
        // ...
    ],

    'permissions' => [
        'description' => '管理平台注册用户和账号状态',
        'actions' => [
            'index'   => '查看用户列表',
            'show'    => '查看用户详情',
            'create'  => '新建用户',
            'store'   => '保存用户',
            'edit'    => '编辑用户',
            'update'  => '更新用户',
            'destroy' => '删除用户',
            'import'  => '导入用户',
            'export'  => '导出用户',
        ],
    ],
];
```

### 5. 带详细说明的动作

```php
'actions' => [
    'destroy' => [
        'title'       => '删除用户',
        'description' => '删除指定用户及其登录账号',
    ],
],
```

`description` 会参与搜索，并作为功能提示展示。

## 四、资源 Controller 中的自定义方法

路由：

```php
$router->post('member-user/{id}/reset-password', [MemberUserController::class, 'resetPassword'])
    ->name('member-user.reset-password');
```

语言包：

```php
'permissions' => [
    'actions' => [
        'resetPassword' => [
            'title'       => '重置用户密码',
            'description' => '为指定用户重新设置登录密码',
            'group'       => '账号安全',
        ],
    ],
],
```

key 必须与 Controller 方法名 `resetPassword` 一致。

## 五、按路由名覆盖

如果同一个 Controller 方法被多条路由复用：

```php
'permissions' => [
    'routes' => [
        'member-user.statistics' => '用户统计',

        'member-user.export-active' => [
            'title'       => '导出活跃用户',
            'description' => '导出当前处于活跃状态的用户',
        ],
    ],
],
```

`routes` 优先级高于 `actions`。

## 六、单路由

单路由推荐在路由定义处直接说明：

```php
$router->get('openapi-docs', [OpenApiDocsController::class, 'index'])
    ->name('openapi-docs')
    ->permissionLabel(
        '接口文档',
        '查看后台 OpenAPI 接口文档',
        '开发工具'
    );
```

参数：

```php
permissionLabel(string $title, ?string $description = null, ?string $group = null)
```

| 参数 | 说明 |
|---|---|
| `$title` | 权限中文名，必填 |
| `$description` | 功能说明，可选 |
| `$group` | 功能分组，可选 |

角色权限页会按 `$group` 将单路由整理成独立分组卡片。每个分组都支持全选、取消全选和半选状态；未设置分组的路由会统一放入“其他路由”。

顶部的“查看类权限”“变更数据类”和“全选”仍然有效，并会与分组选择状态实时同步。

也支持数组格式：

```php
$router->post('system-log/clear', [SystemLogController::class, 'clear'])
    ->permissionLabel([
        'title'       => '清空系统日志',
        'description' => '删除所有系统日志文件',
        'group'       => '系统维护',
    ]);
```

### 闭包路由

```php
$router->get('health', function () {
    return response()->json(['status' => 'ok']);
})->permissionLabel('系统状态', '查看当前服务运行状态');
```

闭包路由没有 Controller 语言文件，应优先使用 `permissionLabel()`。

### 扩展包内置单路由

扩展包自身的认证、通知、系统日志、媒体管理、SKU、Iframe Tab、编辑器上传和开发工具路由，均已在路由定义处配置 `permissionLabel()`。

其中 `dcat-sys/*` 和 `dcat-api/*` 仍属于框架内部路由，不进入角色权限选择；这些说明用于路由自描述、排查和后续扩展，不改变内部路由的权限豁免规则。

UEditor 的配置和上传接口都属于框架内部组件路由，不进入角色权限选择。任何已登录后台角色只要能够访问包含编辑器的业务页面，就可以正常加载配置和上传文件。

新增扩展包单路由时也应同步添加：

```php
$router->post('reports/rebuild', [ReportController::class, 'rebuild'])
    ->permissionLabel('重建报表', '重新计算并生成业务统计报表', '报表管理');
```

## 七、多语言单路由

`permissionLabel()` 可以直接传入翻译结果：

```php
->permissionLabel(
    trans('routes.openapi.title'),
    trans('routes.openapi.description'),
    trans('routes.groups.development')
)
```

如果路由在应用启动时注册，请确保此时 locale 已确定。对于运行时切换语言的项目，更建议使用资源语言包的 `permissions.routes`。

## 八、Scaffold

新生成的 CRUD：

```bash
php artisan admin:scaffold --table=member_users
```

生成的 Lang 文件已包含 `permissions` 结构。开发者只需要：

1. 将 `labels` 改成业务中文名；
2. 填写 `permissions.description`；
3. 必要时将默认动作名改成更明确的业务说明。

## 九、兼容性

- 没有 `permissions` 节点的旧 Lang 文件可继续使用；
- 只要存在 `labels`，资源标题就能显示中文；
- 没有任何 Lang 文件的路由保持原来的 HTTP 方法和 URI 展示；
- `permissionLabel()` 元数据支持 Laravel `route:cache`；
- 扩展包内置资源 Lang 作为默认值，项目同名 Lang 文件可以覆盖；
- 中文说明只影响展示与搜索，不改变实际权限记录的 HTTP 方法和路径。

## 十、排查

修改语言包或路由说明后，如果界面没有更新：

```bash
php artisan optimize:clear
php artisan view:clear
```

如果使用路由缓存：

```bash
php artisan route:clear
php artisan route:cache
```

资源语言包完整字段说明参见：[资源语言包（Lang）结构说明](./资源语言包-lang-结构说明.md)。
